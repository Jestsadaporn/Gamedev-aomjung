# Mini GDD — ภารกิจของหัวใจ v0.1 (Proposed)

เกม top-down ของหัวหน้าหน่วยนักศึกษา สำรวจพื้นที่ใกล้มอเตอร์ไซค์ชมพู พบเพื่อน เลือกชุด ฝึกต่อสู้ แล้วรับข้อความวันครบรอบ ฉากและข้อความเป็นภาพ/บทสมมติ ไม่อ้างความทรงจำจริง เป้าหมาย 12–18 นาทีเป็นสมมติฐาน รุ่นต้นแบบนี้สั้นกว่านั้นและยังไม่ได้จับเวลา

## เส้นทาง
เริ่ม → คุยเพื่อนข้างมอเตอร์ไซค์ → เลือกชุดที่ตู้ → ต่อสู้กับเงา → กลับไปคุยเพื่อน → ฉากจบ แผนขยายเป็นช่วงเปิดเรื่อง 2 นาที สำรวจ/แต่งตัว 4 นาที ภารกิจ/ต่อสู้ 6 นาที จบ 3 นาที หลัง playtest เท่านั้น

## กติกา
เดิน 110 หน่วย/วินาที; โจมตี J หน้าตัวละคร ระยะประมาณ 42 หน่วย สร้าง 1 ดาเมจต่อครั้ง cooldown 0.4 วินาที; หลบ K 0.2 วินาที กันดาเมจ 0.25 วินาที cooldown 0.65 วินาที; ผู้เล่น HP 3, ศัตรู HP 3 เดินตามในระยะ 190 ความเร็ว 42 หน่วย/วินาที, สัมผัสทำ 1 ดาเมจมีช่วงกันซ้ำ 0.7 วินาที; แพ้แล้วเริ่มสนามใหม่ HP เต็ม เก็บชุดและภารกิจ ชุดไม่เปลี่ยน hitbox หรือความสามารถ

| State | เดิน | โจมตี | รับดาเมจ | เข้า / ออก |
|---|---|---|---|---|
| Exploring | ได้ | ได้ | ไม่ | เริ่ม/หลังสู้; คุยหรือเลือกชุดเพื่อไปต่อ |
| Dialogue | ไม่ | ไม่ | ไม่ | คุย / กดต่อ |
| Wardrobe | ไม่ | ไม่ | ไม่ | ใช้ตู้ / เลือกหรือปิด |
| Combat | ได้ | ได้ | ได้ ยกเว้นช่วงกันดาเมจ | เลือกชุด / ชนะหรือแพ้ |
| Defeated | ไม่ | ไม่ | ไม่ | HP หมด / ลองอีกครั้ง |
| Paused | ไม่ | ไม่ | ไม่ | Esc/ปุ่มพัก / เล่นต่อ |
| Ending | ไม่ | ไม่ | ไม่ | คุยหลังชนะ / เล่นใหม่ |

คอม WASD/ลูกศร, E คุย, J โจมตี, K หลบ, Esc พัก; สัมผัสมีปุ่มทิศ/คุย/โจมตี/หลบที่กดพร้อมกันได้ ปุ่มมีขนาดอย่างน้อย 48 CSS px เสนอมือถือแนวนอน มีข้อความแนะนำแนวตั้ง เป้าหมาย iPhone Chrome (รุ่นและเวอร์ชันยังไม่ทราบ) ต้องตรวจเครื่องจริง

## เกณฑ์ตรวจ
PB03: ปุ่มทั้งสองแบบเดินและทำ action พร้อมกันได้; ปล่อย/ยกเลิก/เสีย focus ไม่ค้าง. PB04: ไปเพื่อน ตู้ สนามได้ มอเตอร์ไซค์ชมพูปรากฏ. PB05: โจมตีศัตรูสามครั้ง ชนะ; แพ้แล้วลองใหม่ได้. PB06: เลือกสองชุดได้ มีผลต่อภาพและไม่เปลี่ยนกติกา. PB07: เส้นทางตามลำดับถึงฉากจบ; ข้อความส่วนตัวยังรอยืนยัน. PB09–12: ต้องตรวจภาษาไทยจริง สิทธิ์ build URL อุปกรณ์จริงและจับเวลา ก่อนรับงาน
