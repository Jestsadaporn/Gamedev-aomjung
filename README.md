# ภารกิจของหัวใจ — Anniversary Pixel Web Game

ต้นแบบเกมเว็บ 2D สำหรับของขวัญครบรอบ 6 เดือน เนื้อเรื่องและภาพเป็น placeholder ยังไม่ใช่รุ่นพร้อมส่ง อ่าน [Mini GDD](docs/MINI_GDD.md), [เนื้อหาและ Asset](docs/CONTENT_AND_ASSETS.md) และ [รายงาน Sprint](docs/SPRINT_REPORT.md) ก่อนทำงานต่อ เอกสารต้นฉบับอยู่ใน `anniversary-game-kit/`

ต้องใช้ Node.js 20.19+ หรือ 22.12+ ตาม Vite และ npm จากนั้นรัน `npm install`, `npm run dev` แล้วเปิด URL ที่แสดง; `npm run build` สร้างไฟล์ใน `dist/`, `npm run preview` ตรวจ build ในเครื่อง

ควบคุม: WASD/ลูกศรเดิน, E คุย, J โจมตี, K หลบ, Esc พัก; มือถือใช้ปุ่มบนจอ แนะนำแนวนอน เกมต้นแบบยังไม่มี save หรือเสียง เนื้อหายังไม่ยืนยันและยังไม่ได้ตรวจบน iPhone หรือ URL สาธารณะ
